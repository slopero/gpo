# VIN → страна сборки

Определяет страну производства автомобиля по VIN-номеру. Плюс производитель, год выпуска
и проверка контрольного разряда. Чистый HTML + JS, без зависимостей, работает офлайн.

## Как запустить

### Вариант 1 — двойной клик (самый простой)

Открыть `vin_country/index.html` в любом браузере. Сервер не нужен.

### Вариант 2 — через командную строку

Из корня репозитория:

```bash
python -m http.server 8777 -d vin_country
```

Потом открыть http://localhost:8777

Остановить — `Ctrl+C` в том же окне.

### Вариант 3 — батник

Двойной клик по `vin_country/run.bat` — поднимет сервер на порту 8777 и сам откроет браузер.

## Как пользоваться

Ввести VIN в поле — результат появляется сразу при наборе, кнопку жать не обязательно.
Под полем есть примеры-чипсы, по клику подставляются в поле.

Внизу страницы — раскрывающийся справочник всех диапазонов VIN с поиском по стране или коду.

## Что показывает

| Поле | Откуда берётся |
|---|---|
| Страна сборки | символы 1–2 VIN, таблица ISO 3780 / SAE J853 |
| Регион | символ 1 (Африка / Азия / Европа / Сев. Америка / Океания / Юж. Америка) |
| Производитель | WMI — символы 1–3 |
| Год выпуска | символ 10 |
| Код завода | символ 11 |
| Описание (VDS) | символы 4–9 |
| Серийный номер | символы 12–17 |
| Контрольный разряд | символ 9, считается по SAE J853 |

## Важные оговорки

1. **Страна из VIN — это страна, где зарегистрирован код WMI, а не всегда физический завод.**
   Например, VW с WMI `3VW` собран в Мексике, а `WVW` — в Германии. Если WMI есть в базе,
   под карточкой появляется уточнение по фактическому заводу.

2. **Контрольный разряд (9-я позиция) обязателен только для Северной Америки и Китая.**
   Для европейских VIN несовпадение — это норма, показывается жёлтым, а не красным.
   Алгоритм сверен на эталонных VIN: `1HGCM82633A004352`, `1M8GDM9AXKP042788`,
   `11111111111111111`.

3. **Год выпуска цикличен с периодом 30 лет.** Для Северной Америки цикл разводится
   по 7-й позиции (буква → 2010+, цифра → 1980–2009). Для остальных регионов
   показываются оба варианта.

## Структура

| Файл | Что внутри |
|---|---|
| `data.js` | база: 93 диапазона стран + ~300 кодов WMI с производителями |
| `decoder.js` | логика разбора VIN, контрольный разряд, год |
| `index.html` | интерфейс и стили |
| `run.bat` | запуск сервера одним кликом |

## Как дополнить базу

Новая страна — строка в `COUNTRY_RANGES` в `data.js`:

```js
["XX-XY", "Название страны", "ISO"],   // ISO — двухбуквенный код для флага
```

Новый производитель — строка в `WMI`:

```js
ABC: ["Название марки", "Страна завода"],
```

Порядок символов в диапазонах: `A..Z` без `I`, `O`, `Q`, затем `1..9`, затем `0`.
